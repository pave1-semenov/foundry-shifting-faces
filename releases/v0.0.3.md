# Shifting Faces 0.0.3

## Token gallery and HUD
- Pairings are enabled by default for actors without a saved preference. Existing opt-outs are preserved.
- Wildcard tokens keep the HUD image button even when portrait pairings are disabled.
- The gallery opens in compact **Just tokens** mode, with a portrait preview button on each card. Switch to **Display pairings** for side-by-side token and portrait previews.
- Cards show the effective token name, including applicable pairing overrides, instead of filenames. Search still matches filenames and names.

## Pairing manager and token overrides
- Related controls are arranged in columns within collapsible **Artwork**, **Token overrides**, **Scenescape**, and **Macro / Pair ID** groups.
- Opening a group closes the other groups in that card; other cards stay independent. Group state is retained while the manager updates.
- **Artwork** groups the token image, portrait selection mode, and specific portrait picker. **Token overrides** groups the name and new scale multiplier.
- Per-pairing scale applies to linked and unlinked token artwork, preserves mirroring, and avoids cumulative scaling. Blank overrides restore the original scale; manual scale edits are preserved when removing overrides.

## Scenescape integration
- A new global setting enables integration with Multi Token Edit’s Scenescape feature.
- Pairings can be marked as full-height Scenescape tokens and assigned a physical height. Existing pairings with a positive height start marked unless explicitly unchecked.
- The gallery defaults to **Only Scenescape** on an active Scenescape scene and **Regular tokens** on other scenes. **All tokens** shows both. Search and gallery random selection respect the filter.
- Heights accept feet/ft, meters (m), and centimeters (cm). Values without a unit are centimeters. Saving converts to feet for Scenescape; saved values reopen with an explicit ft suffix to prevent repeated conversion.
- An info icon explains height units, conversion, and blank values.
- Height changes update Scenescape’s size flag and resize existing Scenescape tokens around their feet. Blank heights retain the existing size.
- The macro pairing API includes scale, Scenescape classification, and height in feet.

## Validation
- 31 automated tests pass, covering gallery filtering, wildcard access, scale overrides, height conversion, and existing pairing behavior.
- Live Foundry UI and Scenescape behavior have not been verified in this release session.
